### 🛡️ Trueonic

**Fraud Detection & Identity Risk Platform**

`TypeScript` `Fastify` `Next.js` `PostgreSQL` `Redis` `ClickHouse` `Docker`

- Built multi-tenant fraud and identity-risk systems
- Developed a temporal identity graph linking accounts, devices, browsers, and IPs
- Built explainable risk decisions using rules, evidence, confidence scores, and backtesting
- Added Redis-backed velocity and behavioral checks
- Created Browser, React, and Node.js SDKs
- Built investigator tooling for cases, graph exploration, fraud labels, analytics, and audit logs
- Implemented API keys, RBAC, signed webhooks, validation, tenant isolation, and automated tests

🌐 https://trueonic.com
